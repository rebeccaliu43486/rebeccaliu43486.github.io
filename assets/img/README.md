# Images

- `shsid.png`: the SHSID logo, on the Shanghai stop of the Path
- `raffles.png`: the Raffles Institution crest, on the Singapore school stop
- `photo.jpg` (optional): a square photo, about 400 px. Add it, then set `"photo": "assets/img/photo.jpg"` in `index.html`.

To use another file or format, change `data-logo` on that Path stop in `index.html`.
